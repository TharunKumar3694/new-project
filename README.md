# New Project

## Description
This is a FastAPI-based backend project.

## Features
- User Registration
- Input Validation
- MySQL Database
- REST APIs

## Technologies Used
- Python
- FastAPI
- MySQL
- Pydantic
- Uvicorn

## Installation

1. Clone the repository:
```bash
git clone https://github.com/TharunKumar3694/new-project.git
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the application:
```bash
uvicorn main:app --reload
```
